# Gizachew's Portfolio Website

A modern, responsive portfolio website built with React to showcase my projects and skills as a developer.


##  Features

- **Responsive Design** - Looks great on all devices (desktop, tablet, mobile)
- **Interactive UI** - Smooth animations with Framer Motion
- **Contact Form** - EmailJS integration with real-time validation
- **Form Validation** - Client-side validation for all fields
- **Social Links** - Connected to GitHub, LinkedIn, Telegram, Instagram
- **Modern Styling** - Gradient backgrounds and glassmorphism effects

## 🛠️ Built With

- [React](https://reactjs.org/) - Frontend library
- [Framer Motion](https://www.framer.com/motion/) - Animations
- [EmailJS](https://www.emailjs.com/) - Email service
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) - Styling
- [GitHub Pages](https://pages.github.com/) - Hosting

##  Sections

- **Home** - Introduction with animated background
- **Projects** - Showcase of my work with technology tags
- **Contact** - Form with validation and social media links

##  Validation Rules

The contact form includes:

| Field | Validation Rules |
| :--- | :--- |
| Name | Required, min 3 chars, max 50 chars, letters only |
| Email | Required, valid email format |
| Subject | Required, min 4 chars, letters only |
| Message | Required, min 5 chars, max 1000 chars |
